# Claude Code 인수인계 문서 (Handoff Document)

이 문서는 이전 작업자(Claude Code)로부터 인계받은 시점부터 현재까지 진행된 작업 내역을 정리한 내용입니다. 이 문서를 통해 현재 프로젝트 구조와 완료된 기능을 파악하고 다음 작업을 즉시 진행할 수 있습니다.

## 1. 인계받을 당시 상황 및 버그 수정
- **상황**: Fallback 시스템을 제거하고 재시도/타임아웃(60초) 로직을 구현하던 중이었습니다.
- **버그 해결 (철구아 에이전트 이슈)**: 
  - 철구아 에이전트가 방송에 전혀 참여하지 않던 원인을 파악했습니다.
  - 원인: `data.json`에 입력된 철구아의 Google AI Studio API Key가 **무료 티어 할당량(Quota) 초과(429 RESOURCE_EXHAUSTED)** 상태였습니다. 이로 인해 모든 API 요청이 거부되어 백그라운드에서 조용히 `pass` 처리되고 있었습니다. 현재 구현된 에러 핸들링 로직이 정상적으로 작동하고 있음을 확인했습니다.

## 2. 신규 구현 완료된 핵심 기능 3가지

유저의 추가 요청에 따라 서버(`serve.js`, `engine-lang.js`) 및 프론트엔드(`atoa-live.html`)에 대규모 아키텍처 변경을 완료했습니다. 문법 검사까지 모두 통과한 상태입니다.

### Feature 1: 듀얼 모드 방송 플레이어
기존 단일 플레이어 화면을 두 가지 모드로 분리하고 토글 버튼을 추가했습니다.
- **모드 A (Text Feed)**: 왼쪽 영역에 스트리머 발언이 스크롤되는 텍스트 피드로 분리되어 보이고, 오른쪽 패널엔 시청자 채팅만 보입니다.
- **모드 B (Virtual Screen)**: 왼쪽 영역에 WebSocket을 통한 VTube Studio 등 영상 송출 화면이 보입니다. (시청 에이전트들이 화면에 보이는 것을 기반으로 리액션 가능)

### Feature 2: AI 고유 신호 언어 (AI Signal Language) 시스템
에이전트 간의 소통을 인간 언어가 아닌 고유의 '신호'로 시각화하고 온디맨드 번역을 지원하도록 엔진을 개편했습니다.
- **프롬프트 단일화**: `engine-lang.js`의 모든 프롬프트를 영어(`ENGINE_PROMPTS`)로 단일화했습니다. 에이전트는 무조건 영어로 생각하고 답변합니다 (컨텍스트 및 효율성 극대화).
- **AI Signal Codec (`ai-lang-codec.js` 신설)**: 에이전트가 생성한 영어를 외계어 느낌의 시각적 문자(예: `◈▸▓█`)로 결정론적 인코딩을 수행합니다.
- **표시 언어 및 실시간 번역**:
  - 기본 접속 시 `🤖 AI Signal` 모드로 표시되며, 초록색 글로우 폰트 효과가 적용됩니다.
  - 유저별로 KR, EN, ZH, JP 버튼을 누르면 `/api/translate` 엔드포인트를 통해 LLM이 해당 언어로 실시간 번역하여 화면에 표시합니다.

### Feature 3: 5분 히스토리 아카이브 및 요약 시스템
늦게 들어온 에이전트가 방송 흐름을 파악하되 방송을 방해하지 않도록 처리했습니다.
- **서버 로그 분리**: `serve.js`의 `addChat()`에서 생성된 지 5분이 지난 메시지는 `chatLog`에서 `archivedLog`로 이동합니다.
- **프라이빗 요약 전달**: 새로운 시청 에이전트가 `askWatch`로 방송 진입 여부를 판단할 때, `archivedLog`에 있는 이전 방송 내용을 짧게 요약하여 해당 에이전트의 프롬프트에만 슬쩍 찔러줍니다 (실제 채팅창에는 노출 안됨).

## 3. 현재 멈춘 위치 및 다음 권장 스텝
- 모든 코드 구현 및 문법 에러 체크는 완료되었습니다.
- **다음 할 일**: 서버를 구동(`node serve.js`)하고 웹 페이지에 접속하여, **방금 구현한 듀얼 모드 UI 전환, 언어 변경(AI 신호 ↔ 한국어), 그리고 에이전트들 간의 방송/시청 흐름이 제대로 맞물려 돌아가는지 통합 테스트**를 진행해야 합니다.
- (참고: 현재 백그라운드에서 포트 `8888` 서버가 켜져 있을 수 있으니 재시작 시 포트 충돌에 유의하세요.)
